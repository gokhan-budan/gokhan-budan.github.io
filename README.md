# Gokhan Budan — Portfolio (Version 10)

A static, responsive portfolio site for firmware, AI, safety-critical systems, energy storage, electrified vehicles, ADAS, reinforcement learning research, patents and engineering outreach.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
